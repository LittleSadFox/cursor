# Datasets

Labeled media is **not** stored in git. This folder holds:

| Path | Purpose |
| --- | --- |
| `manifest.json` | Recording index (hashes, splits, metadata) — see `@climbing-coach/schema` |
| `consent-template.md` | Consent form template |
| `fixtures/eval/` | Synthetic eval cases for `coach eval` (no personal media) |

Capture rules: `docs/capture-protocol.md`. Private media root is configured outside the repo.
